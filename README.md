# 🧪 CraftTests - Система тестирования

CraftTests - это веб-приложение для создания и прохождения тестов с административной панелью. Поддерживает различные типы вопросов: одиночный выбор, множественный выбор, текстовый и числовой ответ.

## 📋 Особенности

### Для администраторов:
- ✅ Создание и управление тестами
- ✅ Добавление вопросов с вариантами ответов
- ✅ Поддержка 4 типов вопросов:
  - Одиночный выбор (Single choice)
  - Множественный выбор (Multiple choice)
  - Текстовый ответ (Text)
  - Числовой ответ (Number)
- ✅ Настройка баллов за вопросы
- ✅ Статистика и просмотр результатов
- ✅ Экспорт результатов в CSV
- ✅ Настройка проходного балла
- ✅ Ограничение по времени

### Для пользователей:
- ✅ Прохождение тестов без регистрации
- ✅ Автосохранение ответов
- ✅ Отображение прогресса
- ✅ Результаты после завершения
- ✅ Просмотр деталей ответов
